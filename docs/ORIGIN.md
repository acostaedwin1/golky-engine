# Where this comes from

`golky-engine` is not a weekend idea. It is the domain of a product that has been running
for years, rewritten in the open. The dates below are the real ones.

| When         | What                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2019         | [Golky](https://golky.co) starts as a tool to run amateur football tournaments in Colombia: teams, fixtures, match sheets, standings, fees.                                                                                                                                                                                                                                                                     |
| 2022 → 2025  | Organizers photograph more than ten thousand paper match sheets and type them into the platform by hand, one player per line.                                                                                                                                                                                                                                                                                   |
| mid-2026     | A standings bug in production (`matchesTied = -1`, caused by incremental updates on publish/unpublish) is fixed by recomputing tables from scratch. That decision became this engine's central invariant.                                                                                                                                                                                                       |
| August 2026  | An internal analysis measures the loop: more than 25,000 matches published, ~313,000 player-match rows typed by hand, and a median of days between the final whistle and the published result. The conclusion: use vision models to kill the typing. A viability test with Claude on real sheets reads 10 of 10 players once the image is straightened, cropped by region, and the roster is passed as context. |
| October 2026 | The production code (Java and NestJS services, years of operational config, personal data) was never going to be published as-is. The domain rules are inventoried from it, file by file, and this clean-room TypeScript engine is written against that inventory with Claude Code. First public release.                                                                                                       |

What is deliberately **not** here: real player, organizer or match data; production
infrastructure; anything that identifies a customer. Fixtures in the tests use made-up teams.
